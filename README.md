# まちかどバイト算数 サポート

アプリ「まちかどバイト算数」（英語名 Town Job Math）の紹介ページ（LP）・サポート・プライバシーポリシーです。GitHub Pages で公開しています。

- 紹介ページ（日本語）＋ よくある質問・お問い合わせ: index.html
- 紹介ページ（英語）: en.html
- プライバシーポリシー: privacy.html / privacy-en.html
- 見た目: lp.css（紹介ページ）、style.css（プライバシーポリシー）
- 言語の自動切り替え: lang.js（一度えらんだ言語 → なければブラウザの言語。日本語以外は英語）
- 画像: img/ja, img/en（ゲーム画面。本体リポジトリの MachikadoUnity/Tools/layout-preview で横向き 2532×1170 を 0.6 倍で撮影）、img/chars（キャラクター）、img/og-*.png（SNS 用）
- 英語の声のデータ: voice/
